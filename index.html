Gold rule
Only current 2026 season salmon activity is allowed
This app must not display historical catch returns, old totals, typical averages, or invented projections. Salmon catch and fish counter intelligence must be current-season, source-labelled, and traceable.

Display rule
A fish counter value needs a verified current-year source
Build 10065 deliberately shows no fish counter count. Before any counter number appears, it must have source name, counter location, count type, current-season date, and update timestamp.
Required before display
Counter evidence checklist
  • Source name: organisation or system publishing the count.
  • Counter location: named fish pass, weir, tributary, or counter site.
  • Current-season date: 2026 data only.
  • Count type: salmon, sea trout, total fish, upstream count, downstream count, or other clearly labelled measure.
  • Update timestamp: date/time or reporting period for the value.
No fish counter value is displayed in Build 10065. This is intentional until the current-year source is verified.
